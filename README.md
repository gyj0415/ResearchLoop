# ResearchLoop

面向开放研究问题的科研 Agent：收集证据、提出假设、执行分析或实验、核验结果，再依据反馈修正。支持本地 Ollama 与显式启用的云端 API；研究范围由问题、材料和工具决定。

## 启动

在项目目录双击 `start.bat`，或运行 `./start.ps1`。浏览器访问 <http://127.0.0.1:8768>。

需要 Python 3.12+ 和 NumPy，启动脚本优先使用本项目 `.venv`。本机已有 Ollama `deepseek-r1:8b`、`deepseek-r1:14b`，模型在 `D:/models`。应用不自动下载模型。网页为原生 HTML/CSS/JS，无构建步骤或 CDN 依赖。

## 使用

输入研究问题，可附加 TXT/MD/CSV/JSON（每份最多 500KB）或 PDF/DOCX/PPTX（每份最多 20MB），共最多 8 份。设置模型、token、时间和步骤预算，再开始研究。

Agent 自主选择工具，也可选择先设计多阶段工作流。规划、实验、复核、报告角色控制职责和工具权限；模型选择独立于角色。确定性计算由工具执行，不由模型填写测量值。数值实验冻结代码和判据，以新随机种子复核；定性研究明确来源范围和证据缺口。条件不足时报告未完成。

侧栏研究会话是统一入口。会话内可查看概览、调用链和证据。每次模型请求、重试、工具执行单独记录输入、输出、实际模型、路由原因、用量与耗时。

可以同时启动多个研究，默认最多 3 个同时运行，超出的会话按提交顺序排队。每个会话独立记录材料、状态、预算和调用链；排队期间不消耗研究时间预算。暂停、继续、取消和追问只作用于选中的会话。从运行中的调用节点创建分支会生成独立研究，不会暂停父研究。

“模型设置 → 并行研究”可即时调整同时运行数；降低上限会等待现有研究结束，不会中断它们。多个会话共享模型服务，实际推理并发和速度取决于服务与机器资源。实验子进程的计算线程设为 1，避免每个会话重复创建大型线程池。共享方法记忆的版本发布会串行保存，防止并发覆盖。

- **暂停／继续**：等待当前调用结束后保存状态，原页继续同一轮研究与剩余预算，暂停期间不计研究活动用时。
- **从调用分支**：每条已结算调用可恢复检查点并创建独立会话，不继承该节点之后的结果。填写新方向会先重新决策；留空则继续待执行操作。分支新增用量与继承成本分别记录。
- **记忆**：事实、偏好和研究方法统一管理。新研究自动召回相关记忆；完成且有依据的研究会自动保存方法经验，仍标为待迁移验证。可添加、停用事实或偏好，以及切换方法版本。记忆是待核验上下文，不代替新研究的证据；方法记忆属于带来源的方法说明，不是可执行 skill。
- **模型路由**：设置中配置轻量与高能力模型，可分别使用本地或云端。当前使用可解释规则，常规检查优先轻量档，复杂实验、结论核对及失败修复优先高能力档；未配置档位沿用角色或会话模型。规则选择本身不调用模型，实际请求全部计费。

设置弹窗隐藏滚动条，保留滚轮、触摸与键盘滚动，边界支持弹性回弹；系统要求减少动画时关闭回弹。

旧检索示例及其专用数据准备、调参、验收流程已移除。独立运行记录页与日志页已移除，相关内容统一在会话内查看。科研用文献、网页和平台取证工具继续提供。

## 配置与预算

默认本地推理。可在模型设置显式启用 OpenAI 兼容云端 API，密钥只保存到本机 `config.json`，不会通过状态接口回显或加入 Git。

调用前保守预留 token，调用后记录实际 usage；失败和重试同样计入。拿不到 usage 才使用未知消耗预留；JSON 解析失败不会对已知 usage 重复计费。云端未配置单价时不会把费用表述为零。工具时间单独记录。

## 本地文件

| 路径 | 内容 |
| --- | --- |
| `researchloop/engine/` | 科研循环、角色、工具、路由、检查点 |
| `researchloop/memory.py` | 事实与方法的统一召回和管理 |
| `web/` | 工作台、会话调用链与记忆页面 |
| `runs/` | 原始请求、结果、代码、证据、检查点与文件快照 |
| `data/researchloop.db` | 调用索引、工具注册、事实记忆 |
| `memory/research/` | 方法版本与启用指针 |
| `docs/` | 本地决策、参考与验证记录，按约定不上传 |
| `.qa/` | 项目内测试、浏览器验证依赖和产物 |

归档只隐藏会话，界面删除移入 `runs/.trash`。源码仓库不包含本地配置、模型、数据、运行历史、docs 或展示产物。封存评测数据不因移除示例功能而自动开放。

## 命令行与验证

```powershell
.\.venv\Scripts\python.exe research.py status
.\.venv\Scripts\python.exe research.py run --question "研究样本量对均值估计误差的影响" --steps 12
.\.venv\Scripts\python.exe research.py resume <会话ID>
.\.venv\Scripts\python.exe research.py fork <会话ID> <调用ID> --question "用另一种方法检查"
.\.venv\Scripts\python.exe -m unittest discover -s tests
```

CLI 与网页共享本地文件，应避免同时启动研究。实验子进程限制接口，但不是面对恶意代码的安全沙箱。模型输出和记忆需要证据核验；重新调用模型不保证逐字复现。

调用与会话分离参考 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/architecture.md)；事实记忆参考 [ReEscape Protocol](https://github.com/heky12356/ReEscape-Protocol)。历史测量报告见 [VERIFICATION.md](VERIFICATION.md)，不代表当前新流程已经获得同样收益。
