开启一轮研究

在固定问题集上提出假设、测量效果，再用独立题目验收。

模型负责假设与实验决策；数值计算和验收由代码完成。失败调用与重试也计入预算。

本地与云端模型

主题色只保存在本机浏览器，点选立即生效。

预算上限

研究可用的最大 token、时长与步骤；默认 400000 / 7200 秒 / 40 步，可自行放宽或收紧。

云端 API

默认关闭；启用后通用研究循环可选择云端模型，检索与算子历史流程保持本地。

联网工具

启用后规划角色可用 web_search / web_fetch；抓取会先拦截 localhost 与私有地址。

角色模型

规划、实验、复核、报告可分别指定模型；留空则沿用本轮模型。
